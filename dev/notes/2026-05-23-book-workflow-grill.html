Honest gaps the gate does not catch

  • Behavioral regression: if ggpaintr renames an argument but the old name silently no-ops, the gate passes and the book documents working code that does nothing. Mitigation: precondition #9 — the package's own e2e suite catches this upstream before the pin advances.
  • Shinylive incompatibility: file upload via OS picker, plotly, ggiraph are likely shinylive hazards. Hero chapters must avoid these features, or fall back to screenshot for that chapter.
  • Drift audit coverage: precondition #9 names a per-vignette drift audit, but only some package vignettes have one in dev/audit/ today. Migration of any given vignette is blocked until the audit covers it.
  • Pixel-level visual change: the pair-hash detects "screenshot was not refreshed after fixture edit"; it does not detect "fixture unchanged but the running app now looks different" (e.g. an upstream Shiny CSS change). Acceptable cost — image diff is famously flaky.
